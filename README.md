# A Dog's Intelligence Web Page

This folder contains only Liu Menghan's assigned work for Group 2: the Sample Page Layout website.

## Files

- `index.html` - page structure and the English copy supplied by Chen Yulu.
- `styles.css` - Jello layout, colours, typography, cards and responsive mobile layout.
- `script.js` - mobile navigation and enquiry form interaction.
- `images/happy-dog.jpg` - local hero image used by the page.

## Run in VS Code

Open this folder in VS Code. Right-click `index.html` and choose **Open with Live Server**. If Live Server is not installed, open `index.html` directly in a browser.

## Liu Menghan's design work

The page uses a centred Jello layout, semantic sections, short paragraphs, bullet lists, visible contact guidance, labelled form controls, a skip link and a responsive mobile menu. The colours communicate trust, care, warmth and energy: navy, teal, coral and yellow.

The page content has been updated with Chen Yulu's final web copy: About Us, four services, Service Promise, three testimonials, Get In Touch instructions, email link and footer disclaimer.

## Review fixes

Navigation uses an unordered list. The skip link appears when focused with the keyboard. Links include visited and hover styles, and controls have visible focus outlines. The page includes explicit landmark roles and an SPCA care advice link.

The dog photo is stored locally in `images/happy-dog.jpg`. Include the images folder when sharing the project. Original image source: https://images.unsplash.com/photo-1552053831-71594a27632d

The enquiry form is a front-end demonstration. It validates required fields and shows a message, but does not send or store enquiries.
